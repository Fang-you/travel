# 趣旅行

一款基于微信云开发的旅行服务小程序，提供旅游产品浏览、特价推荐、旅行攻略、订单管理等功能。

## 功能模块

### 首页 (pages/index)
- 城市选择切换
- 搜索功能（支持搜索特价穷游产品）
- 轮播图展示
- 热门推荐产品卡片
- 产品分类入口

### 发现 (pages/discover)
- **旅行攻略**：瀑布流展示用户旅行攻略笔记
- **特价专区**：精选限时特惠产品
- **关于我们**：品牌介绍

### 订单 (pages/order)
- 全部订单
- 待支付订单
- 已完成订单
- 已取消订单
- 订单详情与重新下单

### 我的 (pages/mine)
- 个人资料
- 我的收藏
- 我的拼团
- 优惠券
- 客服中心
- 设置

## 技术栈

- **前端**：微信小程序原生框架
- **后端**：微信云开发（云函数）
- **数据库**：MySQL
- **样式**：WXSS

## 数据库

数据库包含 25 张数据表，符合第三范式设计：

- **用户模块**：管理员角色、管理员用户、地区、用户表
- **产品模块**：产品分类、旅游产品
- **订单模块**：订单主表、订单状态流转
- **内容模块**：攻略、评论、收藏
- **营销模块**：优惠券、拼团活动

详见 [database/trip_database.sql](database/trip_database.sql)

## 快速开始

### 环境要求

- 微信开发者工具
- Node.js（用于云函数开发）

### 配置步骤

1. 导入项目到微信开发者工具
2. 初始化云开发环境
3. 上传云函数
4. 配置数据库并执行建表脚本
5. 修改 `project.private.config.json` 中的 appid

### 云函数部署

```bash
# 上传所有云函数
./uploadCloudFunction.sh
```
